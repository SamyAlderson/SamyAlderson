    ⚡ webx
  </a>
</h3>

> A compiled web programming language built on x86-64 NASM Assembly.

Write your HTML, CSS, and JavaScript as a single compiled source file. **webx** takes it through an assembly-powered compiler pipeline and outputs a complete web page — or a native Linux binary.

- **Compiler**: written from scratch in x86-64 NASM Assembly (~35k LOC)
- **Targets**: Web (HTML/CSS/JS) + Native ELF binaries
- **Origin**: forked from [KDX](https://github.com/yugmerabtene/KDX) by [Yug Merabtene](https://github.com/yugmerabtene), adapted for the web
- **License**: GPLv3
